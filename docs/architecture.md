# How heddlewright is put together

This file is generated by `java -cp target/classes io.github.rkaushikdev.heddlewright.tools.Architecture` after a build. Do not edit it by hand.

## The layers

Lowest first. A class may use classes from its own layer or from any layer
below it, and never from one above.

- **util** (31 files) - numbers, matrices, runs, errors, dates, tables
- **craft** (44 files) - drafting, weave construction, cloth analysis and yarn arithmetic
- **plant** (28 files) - the machines, their card decks and the cloth that comes off them
- **works** (6 files) - orders, scheduling, production, costing and despatch
- **store** (3 files) - the journal and the record projection
- **edge** (15 files) - the http service and the command line
