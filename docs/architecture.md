# How heddlewright is put together

This file is generated by `npm run architecture`. Do not edit it by hand.

## The layers

Lowest first. A file may import from its own layer or from any layer below
it, and never from one above.

- **util** (15 files) - numbers, matrices, runs, errors, dates, tables
- **craft** (41 files) - drafting, weave construction, cloth analysis and yarn arithmetic
- **plant** (25 files) - the machines, their card decks and the cloth that comes off them
- **works** (6 files) - orders, scheduling, production, costing and despatch
- **store** (3 files) - the journal and the record projection
- **edge** (14 files) - the http service and the command line
