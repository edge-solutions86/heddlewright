## Commands

```
command    summary
---------  -----------------------------------------------
boxes      gait a weft order up on a drop box loom

check      report anything wrong with a drawn draft
count      convert a yarn count between systems
deck       cut a card deck for a named weave and price it
draft      draw a named draft and print its cloth
floats     measure the floats in a drawn draft
report     measure a drawn draft every way the package can
sett       work out the sett a cloth and a yarn will take
systems    list the yarn count systems the tool knows
weave      print one repeat of a named weave
```
